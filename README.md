# Lab 2 – Agile Backlog Creation & Sprint Simulation

## Project
**Warehouse Inventory & Pallet Location Tracker**

## Objective
This lab demonstrates Agile backlog creation, prioritization, story point estimation, and sprint simulation using Jira.

## Contents
- Epics and User Stories
- User Story Priorities
- Story Point Estimation
- Sprint 1 Simulation
- Sprint 2 Simulation
- Burndown Charts
- Sprint Reflection

## Jira Project
The project was managed using Jira with Epics, User Stories, priorities, story points, and sprint boards.

## Epics
1. Pallet Location Tracking
2. Inventory Management
3. Shelf Weight Management
4. Barcode and RFID Scanning
5. Stock Movement Tracking

## Sprints
### Sprint 1
Focused on core warehouse inventory tracking features.

### Sprint 2
Focused on additional location, alert, scanning, movement-history, and inventory-update features.

## Story Point Estimation
Fibonacci-based story points were used to estimate the relative effort and complexity of User Stories.
